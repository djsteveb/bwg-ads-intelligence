System Overview

The funnel converts a cold URL entry into a fully-audited account with access, exports, and a clear path to managed services. Each phase can be completed across sessions via email-based async flow — no single visit required.

Phase 1

Discovery Engine

URL entry triggers automated intel gathering on the business, its digital footprint, and ad account signals.

  • Business profile & NAP extraction
  • Google Business Profile match
  • Social presence detection
  • Ad account signals across platforms
  • Domain / hosting intel
Phase 2

Ad Library Surface

Pull active and historical ads from every major platform's transparency tool.

  • Google Ads Transparency
  • Meta Ad Library (with screenshots)
  • LinkedIn Ad Library
  • TikTok Creative Center
  • Bing / Microsoft Ads transparency
Phase 3

Compliance Analysis

AI-driven text and image review against HIPAA, platform health rules, and treatment advertising law.

  • Claims & disclaimer audit
  • Before/after image detection
  • LegitScript signal check
  • 42 CFR Part 2 flags
  • Platform policy violations
Phase 4

Verification & Expansion

Show found ads for confirmation and discover additional accounts, agencies, or shadow campaigns.

  • Screenshot gallery for review
  • Multi-account / page discovery
  • Agency / third-party account check
  • Business Manager mapping
  • Dark post / boosted post surface
Phase 5

Access Request Funnel

Per-platform instructions, templates, and email sequences to collect read-only and export access.

  • Templated instruction emails
  • Grant access guides per platform
  • Export instruction generator
  • Upload portal + email intake
  • Follow-up automation sequences
Phase 6

Deep Audit & Spider

With account access and exports in hand: spider landing pages, check pixels, performance, and compliance.

  • Landing page screenshot + archive
  • Tracking / pixel audit (HIPAA)
  • Core Web Vitals & speed
  • Form functionality checks
  • Ad → page message match score
Phase 7

Journey & Admissions Audit

Full funnel review: awareness to admissions, call quality, CRM, and attribution modeling.

  • Sales / intake call audit
  • Call tracking & script analysis
  • Awareness vs. admissions attribution
  • CRM data integration
  • Coaching gap identification
01

Discovery Engine

Enter a URL. The system auto-discovers everything knowable about the business's digital footprint before touching a single ad platform.

G
Google Business Profile
Match domain → GBP listing. Extract address, phone, category, reviews, business manager signals, service areas.
W
WHOIS & DNS Lookup
Registrar, creation date, nameservers, MX records. Flag if domain is too new (red flag in addiction marketing).
NAP
NAP Consistency Extraction
Pull business name, address, phone from site footer, schema.org markup, and contact pages. Cross-check consistency.
🔗
Social Profile Detection
Discover linked FB page, IG profile, LinkedIn page, TikTok, YouTube. Note connected pixel IDs in page source.
Px
Pixel & Tag Detection
Surface Meta Pixel ID, Google Tag IDs, GTM containers, TikTok pixel, LinkedIn Insight Tag — noted immediately as compliance risk data points.
Sp
Tech Stack Fingerprint
CMS, form tools, chat widgets, call tracking numbers, analytics platforms. Built with Wappalyzer-style detection.
📋
LegitScript Status Check
Search LegitScript database for certification status, past violations. Critical for addiction treatment ad eligibility on Google/Meta.
🏢
State Licensure Signals
Surface state licensing body lookup links for the business's state. Flag if no SAMHSA or state license reference found on site.
02 / 03

Ad Surface & Compliance Analysis

Pull ads from transparency libraries, screenshot them, then run both text and AI image analysis against a compliance ruleset tailored for healthcare, addiction treatment, and beauty/wellness advertisers.

Ad Sources

G
Google Ads Transparency
Search by domain and advertiser name. Surface search, display, YouTube, and Performance Max ads.
M
Meta Ad Library
Active + 7-year archive. Pull all active ads by page. Capture images, copy, CTA, run dates, estimated reach, spend range.
Li
LinkedIn Ad Library
Sponsored content, InMail, and dynamic ads. Pull by company page.
Tt
TikTok Creative Center
Search by advertiser. Surface video ads, hooks, and landing URLs.
Bg
Bing / Microsoft Ads
Live SERP scrape by brand terms. Verify ad copy, extensions, and sitelinks.

Compliance Checks

High Risk — HIPAA / Legal

Healthcare Claims & PHI

  • PHI or patient story identifiers in ad copy
  • Treatment outcome guarantees
  • Bait-and-switch or misleading availability claims
  • 42 CFR Part 2 disclosure violations
  • Unlicensed facility implied claims
Platform Policy — Health Category

Google / Meta Health Rules

  • Non-LegitScript certified addiction treatment ads
  • Sensitive health condition targeting signals
  • Before/after images (prohibited on Meta for health)
  • Missing health claim disclosures
  • GDPR / CCPA consent mode absent from landing page
AI Image Analysis

Visual Compliance Flags

  • Before/after imagery (auto-detected via AI vision)
  • Medical imagery implying clinical services not offered
  • Stock photo overuse (credibility risk)
  • Brand inconsistency across ads
  • Missing disclosures on testimonial images
Landing Page Compliance

Page-Level Checks

  • Privacy policy presence and completeness
  • Tracking pixels firing on intake/contact forms
  • HIPAA-compliant form handling
  • Testimonial FTC disclosure requirements
  • SAMHSA / state license numbers displayed

Additional Ideas & Differentiators

Features that would make this platform genuinely different from anything else in the treatment marketing space.

Competitive Intel

Competitor Ad Surveillance

Monitor named competitors' ad libraries on a schedule. Alert when they launch new campaigns or change messaging.

Compliance Automation

Continuous Compliance Monitor

Weekly automated re-check of all live ads. Alert immediately when a new ad goes live with a compliance flag.

Industry Benchmarking

Treatment Center Ad Benchmark Index

Aggregate anonymized data across TCA clients to surface industry-wide CPL benchmarks and platform mix norms.

Creative Intelligence

AI Creative Scoring

Score each ad's copy and creative against conversion-correlated factors: urgency, insurance mention, CTA strength.

Call Intelligence

Call Transcript Audit

Integrate with CallRail / CTM transcripts. Flag calls where intake staff miss objection handling or HIPAA disclosures.

Attribution

Admission Attribution Modeling

Map first-touch ad → call → intake → admission → payer type. Identify high-LTV admission sources.

Lead Magnet

White-Label Board Report

A version of the business owner report formatted for board presentation to justify ad spend internally.

Automation

Impersonation & Brand Theft Alert

Monitor Meta and Google ad libraries for ads using the client's name or brand assets run by another advertiser.

Tooling

Chrome Extension — One-Click Audit

Browse to any treatment center site, click the extension, surface an instant public-data audit overlay.

Lead Scoring

Prospect Qualification Score

High compliance risk + significant spend + no LegitScript = high-value prospect. Route to sales immediately.

Network Intelligence

Agency Relationship Mapping

Track which agencies are running treatment center ads badly. Build competitive intel on incumbents.

Content

Post-Audit Content Recommendations

Auto-generate a prioritized content brief based on audit gaps. Packaged as an upsell to content services.

Technical Architecture Notes

Data Acquisition Layer

  • Meta Ad Library API (official, rate-limited) + scraper fallback
  • Google Ads Transparency API
  • Playwright / Puppeteer for screenshot capture
  • Screaming Frog-style spider for landing pages
  • PageSpeed Insights API for CWV scores
  • WHOIS / RDAP APIs for domain intel
  • Google Places API for GBP matching
  • LegitScript database query
  • Wappalyzer / BuiltWith API for tech stack

Analysis & Automation Layer

  • Claude / GPT-4V for image compliance analysis
  • Claude for ad copy claims extraction and scoring
  • Session persistence for multi-visit async flow
  • Email automation (Postmark / SendGrid) for drip sequences
  • Webhook-triggered re-scan on access grant
  • PDF report generator (puppeteer-based) per audience
  • Secure file upload portal for export intake
  • CSV / export parser per platform
  • CRM integration hooks (Salesforce, HubSpot)
